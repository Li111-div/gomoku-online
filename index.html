操作教程

从零开始，几步就能和别人下上一局。

0开始之前

  • 需要有人在自己的电脑上运行服务端（双击 start-server.bat）。
  • 服务端启动后会打印一个地址，形如 http://192.168.1.5:8080。
  • 把这个地址发给朋友，大家用浏览器打开这个地址（不是双击网页文件）。
  • 所有人需要连同一个 Wi-Fi / 路由器。

1开一局

  1. 点顶部导航的「对战大厅」。
  2. 先填一个昵称，方便别人认出你。
  3. 点「创建房间」，你会得到一个 4 位房间号。
  4. 把房间号告诉朋友，他在大厅的输入框里填进去、点「加入」。
  5. 人齐了自动开始，房主执黑先手。

2加入别人的房间

  • 大厅的房间列表会实时显示所有房间，状态是「等待中」的点「加入」即可。
  • 如果房间已经开了，你也可以点「观战」进去看。
  • 已经满员的房间只能观战，不能加入。

3对局中能做什么

  • 落子：点击棋盘交叉点，鼠标悬停会显示预览棋子。
  • 胜负：横、竖、斜任意方向先连成五子者获胜。
  • 重新开始：向对手发出请求，对方同意后双方棋盘同时清空。
  • 请求悔棋：撤回双方各一步，同样需要对方同意。
  • 认输：直接判对方获胜。
  • 聊天：左侧聊天面板，打字后回车即可发送。

4常见问题

为什么对局判定要放在服务端？

因为这样可以做到绝对公平、绝不同步出错。落子是否合法、谁连成了五子，全部由服务端一台机器算，客户端只是把结果画出来。客户端哪怕被改过，也无法作弊或算出不一样的结果。

能同时开很多局吗？

可以。每个房间有自己独立的棋局，互相完全隔离。一台服务端同时跑几十个房间都没有问题。

不小心刷新了页面怎么办？

刷新后会自动重连，服务端会把你的席位保留 3 分钟，重连上来就能接着下，棋局不会丢。

朋友打不开我的地址？

按顺序排查：① 是否连了同一个 Wi-Fi；② 地址是否抄错（注意端口号）；③ 服务端窗口是否还开着；④ 电脑的防火墙是否拦截了该端口，可以试着允许 Python 通过防火墙。

服务端崩了会怎样？

所有对局都会中断。因为权威状态只存在服务端，客户端不保留棋局。重新启动服务端后需要重新开局。
